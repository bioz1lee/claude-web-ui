1-4. 이 블루프린트가 주는 전략

① 11번은 무조건 '정적분으로 정의된 함수'다. ∫ax f(t)dt 꼴을 보면 양변 미분 + 적분구간이 0이 되는 x 대입 두 수를 반사적으로 쓴다. 이 한 유형만 완성해도 10점이 고정된다.
② 10번은 무조건 접선이다. "접선을 구한다 → 다른 곡선/축/곡선 자신과의 교점을 구한다 → 도형의 넓이나 길이를 구한다"가 3단 구조 그대로다.
③ 13번 (1)은 항상 치환을 지시한다. sinx = t 또는 cosx = t 로 놓고 −1 ≤ t ≤ 1 을 반드시 명시하는 것이 5점이다.
④ 12번은 Sn 과 an 의 관계다. an = Sn − Sn−1 (n ≥ 2) 와 a1 = S1 의 분리 및 일치 검증을 쓰는 것이 채점 포인트다.
⑤ 소문항은 버리는 문제에서도 (1)만은 쓴다. (1)이 3점 또는 5점이다. 14문항 중 (1)만 전부 써도 약 45점이 확보된다.

핵심 연속한 세 항의 곱은 가운데 항의 세제곱. 삼차방정식을 풀 때 나머지 이차식의 판별식까지 확인해야 "r = 2 뿐"이라고 단정할 수 있다.
10접선이 다른 곡선에 접하는 조건
답 (1) y = 2x + 1  /  (2) k = 0, B(−1, −1)  /  (3) 1
(1) y′ = 3x2 − 1 → x = 1 에서 기울기 2.
y − 3 = 2(x − 1) → y = 2x + 1
(2) 직선이 곡선 y = −x2 + k 에 접하려면 연립한 이차방정식이 중근을 가져야 한다.
−x2 + k = 2x + 1 → x2 + 2x + 1 − k = 0
판별식 D/4 = 1 − (1 − k) = k = 0 → k = 0
이때 x2 + 2x + 1 = 0 → x = −1, y = 2(−1) + 1 = −1 → B(−1, −1)
(3) O(0,0), A(1,3), B(−1,−1)
넓이 = ½|1·(−1) − (−1)·3| = ½|−1 + 3| = 1
기출 대응 1·2교시 10번과 동형(접선 → 타 곡선 접점). "접한다 = 판별식 0"을 명시적으로 쓰는 것이 (2)의 3점이다.
11정적분으로 정의된 함수
답 (1) f(1) = −1  /  (2) f(x) = 3x2 − 6x + 2  /  (3) 11
(1) x = 1 을 대입하면 좌변의 적분구간이 없어지므로 0 = f(1) − 2 + 3 → f(1) = −1
(2) 양변을 x 로 미분한다. 우변의 x f(x) 는 곱의 미분이다.
f(x) = f(x) + x f′(x) − 6x2 + 6x
0 = x f′(x) − 6x2 + 6x → f′(x) = 6x − 6
f(x) = 3x2 − 6x + C,   f(1) = 3 − 6 + C = −1 → C = 2
∴ f(x) = 3x2 − 6x + 2
(3) f(3) = 27 − 18 + 2 = 11
기출 대응 2교시 11번과 동형. 소문항 (1)이 "x = 1 을 대입하라"고 직접 지시하는 형태까지 기출과 같다.
12계차수열
답 (1) a5 = 121  /  (2) an = (3n − 1)/2  /  (3) 543
(1) a1 = 1, a2 = 1 + 3 = 4, a3 = 4 + 9 = 13, a4 = 13 + 27 = 40, a5 = 40 + 81 = 121
(2) n ≥ 2 일 때 계차수열의 합을 이용하면
an = a1 + Σk=1n−1 3k = 1 + 3(3n−1 − 1)/(3 − 1) = 1 + (3n − 3)/2 = (3n − 1)/2
n = 1 에서 (3 − 1)/2 = 1 로 일치하므로 모든 n 에서 성립한다.
(3) Σk=16 ak = ½{Σk=163k − 6} = ½{3(36 − 1)/2 − 6} = ½{1092 − 6} = 543
Σ 의 위끝이 n − 1 이라는 점이 최대 실수 지점이다. n 까지 더하면 an+1 이 나온다.
13사인법칙과 코사인법칙
답 (1) a = 10, b = 14, c = 16, cos C = 1/7  /  (2) 40√3
(1) 사인법칙에 의해 a : b : c = sinA : sinB : sinC = 5 : 7 : 8.
a = 5t, b = 7t, c = 8t 로 두면 둘레 20t = 40 → t = 2.
∴ a = 10, b = 14, c = 16
코사인법칙: cos C = (a2 + b2 − c2)/(2ab) = (100 + 196 − 256)/(2 × 10 × 14) = 40/280 = 1/7
(2) C 는 삼각형의 내각이므로 sin C > 0.
sin C = √(1 − 1/49) = √(48/49) = 4√3/7
넓이 = ½ ab sin C = ½ × 10 × 14 × 4√3/7 = 40√3
핵심 사인의 비 = 변의 비(사인법칙). sin C 를 구할 때 내각이므로 양수라는 한 줄을 쓰지 않으면 부호 근거가 빠진다.
14지수·로그의 대칭성과 도형
답 (1) A(3, 8), B(8, 3), AB = 5√2  /  (2) 55/2
(1) 점 A 의 x좌표가 3 이므로 A(3, 23) = A(3, 8).
y = 2x 와 y = log2x 는 서로 역함수이므로 직선 y = x 에 대하여 대칭이고, A 의 대칭점은 B(8, 3).
(실제로 log28 = 3 으로 곡선 위의 점이다.)
AB = √{(8−3)2 + (3−8)2} = √50 = 5√2
(2) O(0,0), A(3,8), B(8,3)
넓이 = ½|xAyB − xByA| = ½|3×3 − 8×8| = ½|9 − 64| = 55/2
핵심 두 곡선이 역함수 관계임을 쓰면 B 의 좌표를 계산 없이 얻는다. 원점을 낀 삼각형 넓이는 ½|x1y2 − x2y1| 로 즉시 처리한다.
