## 수학 전용판 난이도 설계
| 회차 | 밴드 | 구성 |
|---|---|---|
| 제1·2회 | 실전 상단 재현 | 수능 2~3점 4문항 + 4점 초반 3문항 (평균 3.0점) |
| 제3회 | 안전마진 | 수능 4점 중반 7문항 (평균 4.4점) |

각 회차 후반 3문항은 2개 개념 결합(로그+근과 계수, Sₙ↔aₙ+부분분수, 계차수열+부등식 등).
전 21문항 답은 sympy로 검증했습니다.

## 재생성
```bash

  --print-to-pdf=out.pdf "file://$PWD/eulji-nonsul-practice.html"
```
