## 재생성
```bash
chromium --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=out.pdf "file://$PWD/eulji-nonsul-practice.html"
```
한글 폰트(`fonts-nanum`)가 설치되어 있어야 합니다.
