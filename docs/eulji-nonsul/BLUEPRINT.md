# 을지대 논술 수학 — 기출 블루프린트 (2025 실제 기출 + 2027 모의논술 전수 분석)

분석 원문: 2025학년도 논술고사 1·2·3교시 문제지 및 문항카드 해설, 2027학년도 모의논술고사.

| 9 | 수학Ⅰ | 수열(등차·등비) | 3 | 3+3+4 | 등차중항, 절댓값 조건, Sₙ 조건 |
| 10 | 수학Ⅱ | 미분 | 3 | 3+3+4 | **3세트 모두 접선** |

- 대학 공식 난이도 기준: "고등학교 정기고사 서술·논술형 문항 난이도"

## 난이도 실측

소문항 사다리를 제거한 원 문항 기준 **수능 4점 초반~후반**. 체감 난이도를 낮추는 것은
난이도 자체가 아니라 (1)(2)(3) 단계 제시.

## 수식 조판

수식은 KaTeX로 서버 사이드 렌더링합니다(`render.mjs`). 소스는 `$...$`(인라인),
`$$...$$`(디스플레이) LaTeX이며, KaTeX CSS와 woff2 폰트는 base64로 인라인되어
`eulji-math-blueprint.html` 한 파일만으로 렌더링됩니다.

```bash
npm i katex@0.16.11
node render.mjs r1.html r2.html r3.html out.html
chromium --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=out.pdf "file://$PWD/out.html"
```

## ⚠ 블루프린트 정정 (2026-09-22) — 2026학년도부터 변경됨

2027학년도 논술 가이드북에 수록된 **2026학년도 기출 1·2·3교시**를 분석한 결과,
위에 기록한 2025학년도 블루프린트는 **더 이상 현행이 아니다.**

| 항목 | 2025학년도 | **2026학년도 · 2027 모의 (현행)** |
|---|---|---|
| 소문항 | 8~12번 3개(3+3+4) / 13~14번 2개(5+5) | **전 문항 2개 (5+5)** |
| 8번 | 수학Ⅱ 극한·연속 | **수학Ⅰ 지수·로그** |
| 9번 | 수학Ⅰ 수열 | **수학Ⅰ 삼각함수** |
| 10번 | 수학Ⅱ 미분(접선) | **수학Ⅰ 수열** |
| 11번 | 수학Ⅱ 적분 | 수학Ⅱ 극한·연속 / 미분(극값) |
| 12번 | 수학Ⅰ 수열 | 수학Ⅱ 극한·연속 |
| 13번 | 수학Ⅰ 삼각함수 | 수학Ⅱ 미분 / 적분 |
| 14번 | 수학Ⅰ 지수·로그 | 수학Ⅱ 적분 |
| 난이도 | 수능 4점 초~후반 | **수능 4점 중~후반 (상향)** |

고사 형식(국어 7 + 수학 7, 70분, 총 800점 만점·기본점수 660점)과
출제 범위(수Ⅰ 지수로그·삼각·수열 / 수Ⅱ 극한연속·미분·적분)는 2027학년도도 동일.
