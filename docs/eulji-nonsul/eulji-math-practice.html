2삼각부등식 / 3점
답 π/6 ≤ x ≤ 5π/6
cos2x = 1 − sin2x 를 대입하여 sin x 에 대한 이차부등식으로 바꾼다.
2(1 − sin2x) + 3 sin x − 3 ≥ 0 → −2 sin2x + 3 sin x − 1 ≥ 0
양변에 −1 을 곱하면 부등호 방향이 바뀐다: 2 sin2x − 3 sin x + 1 ≤ 0
(2 sin x − 1)(sin x − 1) ≤ 0 → 1/2 ≤ sin x ≤ 1
sin x ≤ 1 은 항상 참이므로 sin x ≥ 1/2 만 풀면 된다. 0 < x < 2π 에서 ∴ π/6 ≤ x ≤ 5π/6
빈출 실수 — 양변에 −1을 곱하고 부등호를 그대로 두는 것. 단위원에서 sin x ≥ 1/2 구간을 잡을 때 5π/6 을 π/3 로 잘못 읽는 것.

4접선(기울기 조건) / 3점
답 y = 9x − 25,   y = 9x + 7

0 ≤ x ≤ 2 : x2 − 2x ≤ 0 → |·| = 2x − x2
∫02 (2x − x2) dx = [x2 − x3/3]02 = 4 − 8/3 = 4/3
2 ≤ x ≤ 3 : x2 − 2x ≥ 0 → |·| = x2 − 2x
∫23 (x2 − 2x) dx = [x3/3 − x2]23 = (9 − 9) − (8/3 − 4) = 4/3
∴ 합 = 4/3 + 4/3 = 8/3
빈출 실수 — 절댓값을 무시하고 ∫03(x2−2x)dx = 0 으로 답하는 것. 절댓값 정적분은 부호가 바뀌는 점을 먼저 찾는다가 1단계다.

진수 및 밑 조건에서 x > 0. 양변에 밑이 2 인 로그를 취한다.
log2(xlog2x) = log2(8x2)

2절댓값 삼각함수의 실근 개수 / 4점 중반
답 0 < k < 2
y = |2 sin x| 의 그래프를 0 ≤ x < 2π 에서 그린다. 최댓값 2 (x = π/2, 3π/2), 값이 0 인 점은 x = 0, π 이며 x = 2π 는 구간에 포함되지 않는다.
직선 y = k 와의 교점 개수를 k 에 따라 센다.
· k < 0 : 0 개
· k = 0 : x = 0, π → 2 개
· 0 < k < 2 : (0, π) 에서 2 개, (π, 2π) 에서 2 개 → 4 개
· k = 2 : x = π/2, 3π/2 → 2 개
· k > 2 : 0 개
∴ 0 < k < 2
난이도 요인 — 계산이 아니라 그래프 개형과 구간 끝점 포함 여부를 따지는 문항. k = 0 과 k = 2 를 경계에서 따로 확인했다는 서술이 과정 점수의 핵심이다.
3조건 분기 점화식 / 4점 중반
답 19
항을 차례로 계산한다.
a1 = 3 (홀) → a2 = 4 (짝) → a3 = 2 (짝) → a4 = 1 (홀) → a5 = 2 → a6 = 1 → …
a4 이후로는 2, 1 이 반복된다.
a1~a10 = 3, 4, 2, 1, 2, 1, 2, 1, 2, 1
합 = 3 + 4 + (2 + 1) × 3 + (2 + 1) = 3 + 4 + 12 = 19

4미분가능성 / 4점 중반
답 a = 5, b = 4
미분가능하려면 연속이고 좌·우미분계수가 일치해야 한다. 두 조건을 모두 써야 한다.
[연속] 1 + a = b + 2  ···①
[미분계수] x ≤ 1 에서 f′(x) = 3x2 + a → 좌미분계수 3 + a
x > 1 에서 f′(x) = 2bx → 우미분계수 2b
3 + a = 2b  ···②
①에서 a = b + 1 을 ②에 대입: 3 + b + 1 = 2b → b = 4, a = 5
검산: 연속 1 + 5 = 6 = 4 + 2 ✓   미분계수 3 + 5 = 8 = 2 · 4 ✓
빈출 실수 — 미분계수 조건만 쓰고 연속 조건을 빠뜨리는 것. 미분가능성 문제는 조건이 항상 두 개다. 한 조건만 쓰면 답이 나와도 과정 5점 중 3점이 날아간다.
5삼차방정식의 실근 개수 / 4점 중반
답 31개
x3 − 3x2 − 9x = k 로 변형하여, 곡선 y = g(x) = x3 − 3x2 − 9x 와 직선 y = k 의 교점 개수로 본다.
g′(x) = 3x2 − 6x − 9 = 3(x − 3)(x + 1)
극댓값 g(−1) = −1 − 3 + 9 = 5,   극솟값 g(3) = 27 − 27 − 27 = −27
서로 다른 세 실근 ⇔ 극솟값 < k < 극댓값 ⇔ −27 < k < 5
정수 k = −26, −25, …, 4 → 개수 = 4 − (−26) + 1 = 31
빈출 실수 — ① 등호를 포함해 −27 ≤ k ≤ 5 로 두면 중근이 생겨 실근이 2개가 된다. ② 개수를 셀 때 +1 을 빠뜨려 30 으로 답하는 것.
6곡선 위 점까지의 최단거리 / 4점 중반
답 P(1, 1)  (이때 최단거리는 √5)
P(x, x2) (x ≥ 0) 로 두고, 거리 대신 거리의 제곱을 최소화한다(√ 가 있으면 미분이 번거롭고, 거리와 그 제곱은 같은 점에서 최소가 된다).
h(x) = (x − 3)2 + (x2)2 = x4 + x2 − 6x + 9
h′(x) = 4x3 + 2x − 6 = 2(2x3 + x − 3) = 2(x − 1)(2x2 + 2x + 3)
2x2 + 2x + 3 의 판별식은 4 − 24 = −20 < 0 이고 최고차항이 양수이므로 항상 양수. 따라서 h′(x) 의 부호는 (x − 1) 의 부호와 같다.
x < 1 에서 감소, x > 1 에서 증가 → x = 1 에서 최소
∴ P(1, 1), 최단거리 = √{(1−3)2 + 12} = √5
난이도 요인 — 최적화 대상을 거리의 제곱으로 바꾸는 착상과, 삼차식을 인수분해한 뒤 남은 이차식이 부호를 바꾸지 않음을 판별식으로 보이는 단계. 이 판별식 서술이 빠지면 과정 점수를 깎인다.
